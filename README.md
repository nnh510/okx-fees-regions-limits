### Maker 和 Taker 怎么区分

简单理解：

- **Maker**：你的限价单没有立即成交，而是进入订单簿等待撮合。
- **Taker**：你的订单立即与订单簿中的现有订单成交。
- 市价单通常属于 Taker。
- 限价单也不一定都是 Maker。如果限价单提交后立刻与现有订单成交，它仍可能按照 Taker 费率计算。

假设一笔现货交易成交金额为 1,000 USDT，暂不考虑其他费用：

- 按 0.2000% 计算，手续费约为 2 USDT。
- 按 0.3500% 计算，手续费约为 3.5 USDT。

实际扣费还要看成交方向、交易对、账户等级和当地适用费率。某些稳定币交易对也可能使用独立费率，不能简单套用标准表。

## 现货交易适合什么人

如果你的需求是买入或卖出 BTC、ETH 或其他支持的数字资产，现货交易通常是最容易理解的产品。买入后，资产会进入相应账户；卖出后，所得通常以报价资产结算。

现货交易的优点是结构相对直接：

- 不涉及合约到期日。
- 不需要设置杠杆。
- 不会因为保证金不足而触发合约强平。
- 更适合先熟悉交易界面、订单类型和资金划转流程。

但现货交易也不等于没有风险。数字资产价格可能快速上涨或下跌，交易手续费、价差和提现网络费用也会影响最终结果。

对于第一次使用 OKX 的用户，比较合理的顺序是：

1. 先完成身份验证。
2. 小额充值，确认网络和地址无误。
3. 先使用 Convert 或现货限价单熟悉界面。
4. 了解成交记录和手续费明细。
5. 确认提现网络、最小提现数量和到账地址。
6. 熟悉后再考虑其他产品。

OKX 官方说明，个人账户需要完成高级身份认证后才能使用交易、充值和提现等功能。身份验证通常需要提交居住国家、姓名、出生日期、证件和自拍等信息。资料准确且清晰时，部分审核可能很快完成；如果需要人工复核，可能最长需要 24 小时。

## Convert、现货和合约有什么差别

OKX 的产品较多，刚注册时不必一次全部打开。可以先按照交易复杂度理解：

### Convert

Convert 适合希望快速把一种资产换成另一种资产的用户。官方产品页面将其描述为快速转换功能，并标注零交易费和无滑点等产品特点，但具体报价、可用资产和地区限制仍应以交易确认页面显示为准。

它的优点是操作步骤少，不需要研究订单簿。缺点是报价结构不像限价单那样容易控制，金额较大时最好对比确认页面的实际汇率和预计到账数量。

### 现货交易

现货适合希望自行选择价格和订单类型的人。你可以使用市价单快速成交，也可以使用限价单等待目标价格。

如果你比较在意交易成本，应该关注：

- 当前账户费率等级。
- Maker 或 Taker 类型。
- 交易对的流动性。
- 订单最终成交价格。
- 是否存在特殊币对费率。

### 合约和期权

合约允许用户使用保证金交易永续或交割合约，部分产品支持杠杆。OKX 的产品页面还列出了 Events & Options 等衍生品功能。

这类产品不适合仅仅因为“手续费看起来更低”就直接尝试。杠杆会放大收益，也会放大亏损；资金费率、维持保证金、标记价格和强平规则都需要先弄清楚。

美国用户还需要额外注意产品限制。OKX 官方明确说明，美国地区并不提供所有境外平台功能，部分服务会受到联邦、州和账户资格限制。

## 交易机器人和跟单功能值得用吗

OKX 目前提供网格、DCA、定投、套利等类型的交易机器人，帮助用户按照预设规则执行策略。官方帮助中心列出了 Spot DCA、Spot Grid、Futures Grid、Recurring Buy 等功能说明。

交易机器人适合有明确规则、希望减少手动操作的人，但它不会自动消除市场风险。网格策略在震荡市场中可能更容易体现设计逻辑，但遇到持续单边上涨或下跌时，持仓结构可能与预期不同。

跟单交易则是复制其他交易者的交易行为。OKX 官方说明，跟单交易会按照领单交易者的操作自动开仓和平仓，用户仍需关注交易费和利润分成。部分地区不支持跟单交易，美国、加拿大、英国等地区在官方 FAQ 中被列为不支持地区。

因此，跟单不应该被理解为“把交易交给别人就不用管了”。选择交易者时，至少要看：

- 历史交易周期。
- 最大回撤。
- 使用的杠杆。
- 单笔仓位。
- 盈利是否依赖少数几次交易。
- 是否存在利润分成。

历史收益不能保证未来结果，尤其是高杠杆策略。

## 入金、提现和网络费用

加密货币充值通常不收 OKX 平台入金手续费，但提现会产生网络费用。OKX 官方说明，提现费用会根据资产、网络拥堵、链上成本和平台当前设置变化，实际费用应以提现页面显示的金额为准。

提交提现前，建议核对四件事：

1. 币种是否正确。
2. 网络是否与收款平台一致。
3. 地址是否完整且没有复制错误。
4. 最低提现数量和预计到账数量是多少。

例如，向支持 ERC-20 的地址提现时，不能因为地址格式相似就随意选择其他网络。网络选错可能导致资产无法自动到账，后续处理也不一定能够恢复。

法币提现则取决于所在地区、账户验证状态和支付渠道。OKX 官方说明，可用的法币、提现方法、处理时间和费用会根据地区显示，部分方式可能即时到账，部分方式可能需要多个工作日。
